# JavaScript-Projects
JavaScript Course Projects
A collection of projects I completed while learning and practicing JavaScript. Each project helped me work with different programming concepts and build interactive web applications.

Projects
Pizza Menu

Tic-Tac-Toe Game

Calculator

Pizza Menu
An interactive pizza ordering page where users can choose from different toppings and customize their order. The application uses JavaScript to process the selections and calculate the final cost.

Tic-Tac-Toe Games
A browser-based version of the classic Tic-Tac-Toe game. Two players can take turns placing their symbols on the board, with JavaScript checking for winning combinations and draws.

Calculator
A simple calculator designed to perform common mathematical operations. Users can enter numbers and use addition, subtraction, multiplication, and division through an easy-to-use interface.

What I Learned
Throughout these projects, I practiced JavaScript fundamentals such as functions, variables, conditionals, user input, event handling, and DOM manipulation.
